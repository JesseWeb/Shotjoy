# Shotjoy（截趣）— name and search notes

## Why this name

**Shotjoy** = *shot* + *joy*.
**截趣** = *截*（screenshot/capture）+ *趣*（fun, delight）.

- Short, positive, easy to remember.
- Says what it does without being a generic "screenshot tool".
- Unique in the macOS screenshot category, so a search for the brand can find
  this project instead of a crowded keyword page.
- Works as a bilingual brand: `Shotjoy（截趣）`.
- Tagline: **Screenshots, with joy. / 截图，也可以很有趣。**

## Names checked and avoided

These were considered and rejected because they are already used by screenshot
or photo products (or are too close to one):

- SnapMark, ShotMark
- Snapora, Shotora
- Shotwright, JotShot
- ShotBloom, Shotcove, SnapGleam
- SnapZen, ShotZen
- Snapmark / ShotSmith

Re-check domains, App Store names, and trademarks before a public launch. A
reasonable first choice is `shotjoy.app` and the handle `@shotjoyapp`.

## Search strategy

1. Keep the brand unique (`Shotjoy`, `截趣`) and put the category words in the
   subtitle/description, not in the brand.
2. Use the first README paragraph and the GitHub description for the exact
   phrases people search: "macOS screenshot tool", "WeChat-style screenshot",
   "截图标注", "长截图", "贴图", "文字识别".
3. Publish a short demo video/GIF with the shortcut `⌃⌘A` in the first frame.
4. Use consistent handles and the same icon everywhere.
5. Do not keyword-stuff; the unique brand is the SEO asset.
